Этот учебный проект предназначен для получения опыта программирования на Django. 
Готовый проект задуман как интернет-магазин с несколькими основными приложениями: 
- Приложение по работе с товаром: отображение общее и по категориям, страница товара,
сортировка, фильтрация, работа с админкой.(На стадии программирования)
- Приложение для покупателей: личный кабинет, корзина, избранное (на стадии проектирования UX)
- Приложение для продавцов: управление обработкой заказов (ожидает в очереди )
- Api для мобилок (изучаю как)

- На данный момент в репозитории отображен процесс разработки приложения "goods".
  Здесь фокус направлен на реализацию технической стороны, UI и frontend реализованы на минимально возможном уровне,
  достаточном для разработки и тестирования продукта
