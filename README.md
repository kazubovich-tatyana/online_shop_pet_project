Этот учебный проект предназначен для получения опыта программирования на Django. 
Готовый проект задуман как интернет-магазин с несколькими основными приложениями: 
- Приложение по работе с товаром, включает: отображение общее и по категориям, страница товара,
сортировка и фильтрация, админ панель.(На стадии программирования)
- Приложение для покупателей: личный кабинет, корзина, избранное (на стадии проектирования UX)
- Приложение для продавцов: управление обработкой заказов (ожидает в очереди )
- Api для мобилок (изучаю как)

- На данный момент в репозитории отображен процесс разработки приложения "goods".
  Здесь фокус направлен на реализацию технической стороны, UI и frontend реализованы на минимально возможном уровне,
  достаточном для разработки и тестирования продукта
  __________________________________________________________________________________________________________________
  This training project is designed to get programming experience in Django. The final product is envisioned as an e-commerce platform with several core apps.
  - Product Management App (in development): includes general and category views, product detail page, sorting and filtering, Admin panel.
  - Customer App (UX design stage): user profil, basket, wishlist.
  - Seller App ( in queue): order processing management
  - API (learning how to do this)
  Currently, the repository displays the development process of the "goods" app.
  This project focuses mainly on the backend side, the UX and frontend are minimal, just enough to develop and and test the project.
